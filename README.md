# Ben Church's blog

Poems use `categories: ["Poems"]` in their Markdown or MDX frontmatter. The
`Poems` tag appears automatically on the post and listing. Published poems only
appear in the homepage listing when the “For them” filter is selected
(`?filter=for-them`), even if they also have other tags. The filter includes both
poems and posts tagged `For them`; poems do not need both tags.
